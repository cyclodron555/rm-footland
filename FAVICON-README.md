# Favicon Protection

The Cyclodron favicon features a golden letter "C" and should NOT be replaced by v0's default favicon.

## Current Favicon Files:
- `/public/icon.svg` - Main favicon (golden C)
- `/public/favicon.ico` - ICO format (golden C)
- `/public/apple-icon.jpg` - Apple touch icon
- `/public/icon-dark-32x32.jpg` - Dark mode variant

## DO NOT:
- Replace these files with v0 default icons
- Update to generic favicons
- Change the golden "C" branding

## Logo Usage:
- **Favicon**: Use `/public/icon.svg` (golden C)
- **Website/Links Page**: Use `/public/logo.png` (full Cyclodron logo)
